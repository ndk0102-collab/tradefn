# d1_buyers_raw.xlsx 데이터 사전 (변수 정의서)

- 대상: `data/day1/d1_buyers_raw.xlsx` → `buyers` 시트, 153행 × 23열 (바이어 150곳 + 중복 3행)
- 기준일: 2026-09-30 (`readme` 시트)
- 출처
  - 뜻 · 유형 · 단위 · 허용값: 과정 배포 `data/data_dictionary.xlsx`의 `columns` · `codes` 시트. 그 시트 문구를 줄여 옮겼습니다.
  - 결측 수 · 관측 범위: [`scripts/d1_buyers_quality_check.py`](../../../scripts/d1_buyers_quality_check.py)의 1절 · 6절 출력값
    (실행: `uv run python scripts/d1_buyers_quality_check.py`)
- 결측 수 = 원본 153행에서 **빈칸인 셀** 수. `-` · `확인중` 같은 글자는 결측에 넣지 않고 메모에 적었습니다.
- 관측 범위 = 완전 중복 1행(B047)을 뺀 150행에서 **숫자로 저장된 셀만** 본 최소 ~ 최대(중앙값). 글자로 저장된 숫자(`49.2k` 등)는 빠져 있습니다.
- 표기 문제의 자세한 내용은 [d1_quality_report.md](d1_quality_report.md)에 있습니다.

## 2. 재무 지표 4개 — 공식과 위험 방향

| 열 이름 | 공식 (사전 원문) | 단위 | 위험 방향 | 해석 메모 |
|---|---|---|---|---|
| `current_ratio_fy2025` | 유동자산 ÷ 유동부채 | 배 | **낮을수록 위험** | 1년 안에 갚을 빚을 1년 안에 현금이 될 자산으로 얼마나 덮는지. 1 미만이면 유동자산이 유동부채보다 적다. 이 파일 요약문도 1.0을 기준으로 씀: `Current ratio below 1.0 (0.96).` (13행 B012 `fin_summary_text`) |
| `debt_to_equity_fy2025` | 총부채 ÷ 자기자본 | 배 | **높을수록 위험** (단, 음수는 별도) | 자기자본 대비 빚의 크기. **음수 = 자본잠식(비율 해석 불가)**(사전 원문) — 숫자가 작아 보여도 가장 위험한 축이므로 크기 비교 · 평균에서 빼고 따로 표시 |
| `dso_fy2025` | 매출채권 ÷ 매출 × 365 | 일 | **높을수록 위험** | 외상 매출을 현금으로 회수하는 데 걸리는 평균 일수. 길수록 바이어 자신의 현금 회수가 늦다 |
| `op_margin_fy2025` | 영업이익 ÷ 매출 | 비율(소수, 0.08 = 8%) | **낮을수록 위험** | 본업에서 남기는 이익 비율. 음수 = 영업손실. 요약문 표기 예: `operating loss (-24.9% margin)` (14행 B013) |

- 공식은 `data/data_dictionary.xlsx` → `columns` 시트 '설명' 열 원문입니다.
- **위험 방향은 데이터 사전에 적혀 있지 않습니다.** 위 방향은 일반적인 재무분석 해석이고, 음수 부채비율 설명만 사전 원문입니다.
- 위험을 가르는 기준값(예: 유동비율 몇 배 미만이면 위험)은 이 저장소 자료에 정해진 것이 없어 적지 않았습니다. 유동비율 1.0은 위 요약문에 쓰인 표현일 뿐 과정이 정한 기준이라는 근거는 없습니다 — 기준은 사람이 정합니다.

## 3. 사용 시 주의

| 주의 | 대상 열 |
|---|---|
| 통화가 섞여 있음 — 통화 통일 전 합계 · 비교 금지 | `ar_balance`, `overdue_amount` |
| 빈칸이 '0'이 아니라 '모름'·'해당 없음' — 0이나 평균으로 채우지 않음 | `pay_score`, 재무 5열, `industry` |
| `-`가 정해진 뜻을 가짐 — 숫자 0으로 바꾸지 않음 | `oecd_crc` |
| 원천 표기 열 — 분석에는 코드 열 · 변환표를 씀 | `country` → `country_code`, `payment_terms_raw` → `payment_terms_map` |
| 숫자 · 날짜가 글자로 저장됨 — 2일차 정제 대상 | `ar_balance`, `max_dpd_days`, `overdue_amount`, `since_date` |
